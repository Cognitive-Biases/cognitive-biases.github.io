# Multilingual content

English is the canonical editorial language for the project. German and Russian should be maintained as reviewed language layers, not as separate copies of the knowledge base.

## One meaning, several languages

The following parts belong to the canonical record and should not be independently rewritten per language:

- concept identifier and canonical slug;
- kind and family;
- evidence status;
- sources and DOI links;
- relationships between concepts;
- review and update dates.

Language layers contain the parts a person reads:

- display title;
- summary;
- explanation;
- examples;
- practical questions;
- research-note prose.

## Translation rule

Translate the reviewed meaning, not the English sentence structure.

A German or Russian page should sound natural to a native reader. It may use different sentence order or examples when needed, but it must not strengthen or weaken the scientific claim.

When an English evidence review changes materially, related translations should become "needs review" until they are checked against the new canonical meaning.

## URLs

Keep the existing English URLs stable.

Use language prefixes for additional versions:

- `/de/...`
- `/ru/...`

Each translated page should point to the canonical language alternatives through the appropriate language metadata. Do not automatically redirect a reader based only on location or browser language.

## Translation workflow

1. Translate only from reviewed canonical material when possible.
2. Keep source titles and stable source links unchanged unless an official translated title exists and is useful.
3. Review terminology for consistency within the language.
4. Read the page as prose, not as a line-by-line translation exercise.
5. Check that uncertainty words remain equivalent: "may", "often", "mixed", "limited" and similar qualifiers are scientifically meaningful.
6. Record the canonical review version or review date the translation is based on.

## Rollout

Do not translate all legacy entries at once.

Start with:

1. home, About, Research and Data pages;
2. evidence-reviewed entries;
3. high-value decision contexts and comparisons;
4. the remaining library as entries receive review.

This keeps translation effort tied to the strongest parts of the project instead of multiplying old generated copy.
