# Search intent policy

Search growth should follow real decision questions that the reviewed library can already answer.

A guide is generated only when enough evidence-reviewed concepts match one maintained editorial intent. The first themes cover forecasting, AI-assisted decisions, information verification, project/product decisions, social judgment and sunk-cost decisions.

Rules:

- one guide must answer one distinct human question;
- do not generate pages from arbitrary keyword combinations;
- do not copy a bias definition into several near-duplicate pages;
- keep unreviewed concepts out of indexable decision guides;
- link from the question to reviewed evidence, decision contexts and comparisons;
- do not create a page merely because a keyword has search volume.

The purpose is better discovery of useful reviewed knowledge, not a larger sitemap.
