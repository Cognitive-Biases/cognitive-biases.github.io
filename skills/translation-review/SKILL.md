# Translation review

Use this skill when creating or reviewing a non-English version of Cognitive Biases content.

## Goal

Make the page sound natural in the target language while preserving the meaning, limits and evidence status of the canonical reviewed content.

## Process

1. Read the canonical English record and its evidence review.
2. Identify the claims that must not change in strength.
3. Translate the meaning rather than the sentence structure.
4. Use natural terminology for the target language and keep it consistent across related concepts.
5. Preserve uncertainty words and boundary conditions.
6. Keep source identifiers, DOI links and canonical relationships unchanged.
7. Read the finished page as normal prose and remove literal translation artefacts.
8. Mark the translation for review when the canonical evidence changes materially.

## Rules

Do not translate an unreviewed legacy claim into a more confident statement.

Do not invent local examples that change the phenomenon being described.

Do not translate paper titles unless an official translated title is useful and verifiable.

Do not treat machine translation as final editorial review.

## Result

Return:

- target language;
- canonical source version or review date;
- translated content;
- terminology notes if needed;
- any claim that needs subject-matter review before publication.
