# Cognitive Biases → Vedokrok

Cognitive Biases is now part of [Vedokrok](https://vedokrok.com), a broader practical knowledge system.

## Project history

1. **Experiment.** Cognitive Biases started as an educational mobile app, then grew into a public website and knowledge library for recognizing errors in thinking.
2. **Lessons.** Running the project showed what readers actually use: clear explanations, honest evidence states, comparisons between easily confused ideas and real decision contexts — and what it costs to maintain all of that well.
3. **Consolidation.** The website was consolidated into a reviewed reference: evidence notes, sources, public data and explicit quality limits, with legacy material kept visible rather than silently dropped.
4. **Vedokrok.** The project's strongest ideas and content now live on inside Vedokrok, which pairs awareness of thinking errors with concrete tools for better decisions, learning and action — across many areas of life and work.

## What this means

- The site stays online at <https://cognitive-biases.github.io> as a historical project and a useful standalone reference.
- No redirects: every existing URL continues to serve its page.
- Content is preserved: pages, public data releases, evidence states and provenance remain as published.
- Active development continues at Vedokrok; this repository changes only for maintenance.
